Formatos GDAL disponibles

Esta aplicación web permite transformar entre formatos de archivos y entre sistemas de referencia de coordenadas (SRC) de forma sencilla, completamente en cliente (sin envío de datos a servidores), gracias a gdal3.js.

¿Qué es GDAL?

GDAL (Geospatial Data Abstraction Library) es la biblioteca de referencia para la lectura, escritura, reproyección y transformación de datos geoespaciales vectoriales y ráster. gdal3.js la compila a WebAssembly mediante Emscripten, permitiendo ejecutar GDAL directamente en el navegador con un rendimiento cercano al nativo.

Características

  • Apertura de archivos individuales y comprimidos en ZIP.
  • Detección automática del SRC cuando está disponible en los metadatos.
  • Reproyección entre sistemas de referencia definidos por EPSG.
  • Conversión entre los formatos soportados por GDAL.
  • Generación automática de GeoJSON para su visualización en el mapa.
  • Descarga del resultado, con generación de ZIP cuando se producen múltiples archivos.
  • Visualización de los datos mediante API-IDEE.
